void urp_hardware_clear_transmit ( struct urp_parallel_bus *  bus)

Immediately clear the RTX transmit output without serial reprogramming.

Parameters
busParallel-port value and caller-supplied write callback.

This is the hardware-worker fail-safe path. It leaves frequency-programming bits untouched so a disconnect or stop cannot delay transmitter release.
