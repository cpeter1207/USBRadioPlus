Detailed Description

Synchronous taskprocessor envelope; never call from an audio callback.

Only the selected input record is used. Snapshot storage is initialized by the host. A zero result and accepted ABI confirm success; otherwise the result is a product error or -1 for malformed/unsupported transport. No new device is opened. A successful write means queued, not physical readback.
