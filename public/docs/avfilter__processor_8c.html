◆ slot_wait_for_readers()

static void slot_wait_for_readers ( const struct txagc_avfilter_slot *  slot)
static

Wait until no worker or control-plane reader can still reference a replaced graph.

Parameters
slotSlot whose active pointer was already replaced.

Active-pointer publication and the reader count use one sequentially consistent order. A reader increments first and then loads active; a writer stores a replacement and then observes readers. If the writer sees zero, every later reader must load the replacement. Otherwise the reader pins the old graph until this wait completes. This prevents a worker from acquiring a graph after its old allocation has been retired without putting a lock in the audio callback.

AVFILTER_PRIVATE int txagc_config_equal ( const struct txagc_config *  left,
const struct txagc_config *  right 
)

Compare every named configuration member without reading padding.

Parameters
leftFirst validated graph configuration.
rightSecond validated graph configuration.
Returns
Nonzero when both configurations have the same semantic values.

Configuration values cross the control-plane/real-time boundary and contain compiler-inserted padding. Do not replace this explicit semantic comparison with a bytewise object comparison: padding is not configuration and can make an unchanged reload spuriously rebuild a graph. Stage-order entries beyond stage_count are also deliberately ignored because graph construction never reads them.
