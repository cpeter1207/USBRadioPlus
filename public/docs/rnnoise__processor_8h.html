◆ txagc_rnnoise_prepare()

int txagc_rnnoise_prepare ( struct txagc_rnnoise *  state,
unsigned int  sample_rate 
)

Allocate or reconfigure RNNoise state before native callback processing.

Parameters
stateProcessor state owned by the radio channel.
sample_rateNative input sample rate in Hz.
Returns
Zero when a reusable denoiser and converters are ready, otherwise nonzero.

A successful call makes txagc_rnnoise_process_prepared() allocation-free. The native receiver uses a fixed 48 kHz rate and prepares this state before its first native callback render.
