◆ usbradioplus_hardware_assignment

enum usbradioplus_hardware_assignment

Hardware voice/transmit-signaling routing values shared with channel adapters.

The configuration spells the signaling routes ctcss and voice_ctcss, but either route carries the selected CTCSS or DCS waveform.

Enumerator
USBRADIOPLUS_HW_OFF 

Silence on this hardware output.

USBRADIOPLUS_HW_VOICE 

Processed voice without transmit signaling.

USBRADIOPLUS_HW_CTCSS 

Transmit signaling without voice.

USBRADIOPLUS_HW_VOICE_CTCSS 

Processed voice mixed with transmit signaling.

USBRADIOPLUS_HW_AUX_VOICE 

Auxiliary voice routing.
