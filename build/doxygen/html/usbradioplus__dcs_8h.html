int urp_dcs_process ( struct urp_dcs_state *  state,
const int16_t *  samples,
size_t  count,
size_t  stride,
unsigned int  sample_rate 
)

Process native-rate discriminator samples and update the qualified receive result.

Parameters
stateDecoder state.
samplesFirst selected-channel discriminator PCM sample.
countNumber of selected-channel samples.
strideSample spacing in 16-bit PCM words; one for mono and two for stereo.
sample_rateInput sample rate in Hz.
Returns
Nonzero when the configured receive DCS is currently decoded.

A previously qualified receiver clears after URP_DCS_TURNOFF_MINIMUM_MS of a coherent 134.4 Hz DCS turn-off tone. The detector is energy- and coherence-gated, so ordinary DCS data, silence, and broadband discriminator noise do not constitute a turn-off tail.
