Detailed Description

Attach the radio's configured link graph before reading peer audio.

Call on the control plane before starting the peer reader. The caller retains the peer channel until this synchronous call returns; the peer datastore then owns the hook. Disabled processing retains the profile for later reloads. Repeating the same binding is harmless; rebinding to another profile fails. Require both a zero return and the accepted ABI: Asterisk can return success for options unknown to an older driver. No public loader ABI changes.
