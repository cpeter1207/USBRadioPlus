Allocate or rebuild a shared FFmpeg graph outside the audio callback.

Parameters
stateProcessor or stream state owned by the caller.
configFilter and dynamics settings for the shared FFmpeg graph.
sample_rateAudio sample rate in Hz.
Returns
Zero on success; a negative FFmpeg error code on failure.

This control-plane operation creates the graph, its fixed FIFO, and a pool of reusable frames. Call it before using txagc_avfilter_process_prepared() from a real-time audio callback and after each settings or rate change.
