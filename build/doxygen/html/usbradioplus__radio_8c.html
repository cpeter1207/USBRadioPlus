◆ urp_radio_process_timed()

i16 urp_radio_process_timed ( urp_radio_state *  PmrChan,
i16 *  input,
i16 *  outputrx,
i16 *  outputtx,
int  advance_tx 
)

Advance a radio-signaling block while optionally freezing TX time.

Receiver processing always advances. A hardware callback passes zero for advance_tx when its DAC cannot accept the matching output frame so CTCSS, DCS, PTT, and transmitter-tail state cannot run ahead of rendered audio.

Parameters
PmrChanRadio-signaling engine state.
inputInput samples; the caller retains ownership.
outputrxBase-rate receiver output buffer.
outputtxTransmitter scratch buffer retained by the radio interface.
advance_txNonzero to advance transmitter signaling for this block.
Returns
Zero after a processed block; one when processing cannot proceed.
