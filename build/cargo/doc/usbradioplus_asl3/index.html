Single ASL3 compatibility boundary for USBRadioPlus.

This crate owns Asterisk-rate PCM representation, controller compatibility state, and the lock-free handoff from native audio callbacks to a non-real-time Asterisk delivery owner. It contains no radio DSP, hardware I/O, Asterisk types, logging, or audio-thread allocation.
