Struct StationPlan

Source 
pub struct StationPlan { /* private fields */ }
Expand description

Immutable product-composition plan for one resolved channel generation.

Construction performs no external I/O and does not alter a running station. A reload can therefore retain its active generation whenever planning or subsequent preparation fails.
