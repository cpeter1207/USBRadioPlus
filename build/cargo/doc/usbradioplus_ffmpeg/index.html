Safe ownership around the versioned external FFmpeg graph descriptor.

This private Rust component is the only USBRadioPlus code that knows the external adapter’s C layout. The adapter-neutral core supplies graph text and normalized F32 buffers without importing any FFmpeg or adapter type.
