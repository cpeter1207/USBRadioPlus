Struct HardwareMaintenance

Source 
pub struct HardwareMaintenance { /* private fields */ }
Expand description

Single physical maintenance owner shared by ASL3 and native compositions. Mixer conversion, EEPROM coding and bounded GPIO commands have one implementation. Audio callbacks only read its shared atomic request and measurement snapshots.
