Crate usbradioplus_radio

Source
Expand description

Safe ownership for the ABI-4 whole-session radio core.

Product composition validates the process-lifetime descriptor and prepares all borrowed processing ports on its control plane. A prepared session then splits exactly once into independent receive and transmit callback owners plus one control observer. The callback methods operate only on exact, bounded normalized-F32 spans at the fixed 48 kHz native rate.
