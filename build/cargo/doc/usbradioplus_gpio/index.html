Source
Expand description

Safe ownership for the versioned CM119 and parallel-port GPIO adapter.

The external adapter retains all USB HID and operating-system I/O. This crate validates its descriptor, owns device handles, and exposes typed control and snapshot operations. Only lock-free publication and snapshot methods may be called from a native audio tick; Cm119Device::service and ParallelDevice::service belong to one non-real-time service owner.
