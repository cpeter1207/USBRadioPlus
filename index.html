USBRadioPlus Debian packages

Signed alpha packages for supported ASL3 releases on Debian 12 and Debian 13.

Download and run the installer. It detects the node version and selects the matching package:

curl -fsSLO https://cpeter1207.github.io/USBRadioPlus/install-usbradioplus.sh
sudo sh install-usbradioplus.sh

The installer shows its plan and asks before changing the node. It does not edit Asterisk configuration, activate the module, or restart Asterisk.
